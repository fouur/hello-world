# hello-world

This repository now includes a small Flask application that implements a
simple file tagging system. Tags have a name and color, and files can be
associated with one or more tags. You can view tags, add new ones, tag
files, and click a tag to see all tagged files.

## Requirements
- Python 3
- Flask (`pip install Flask`)

## Usage
Run the app with:

```bash
python app.py
```

Then open `http://127.0.0.1:5000/` in your browser. You can manage tags
and file paths from the web interface.
